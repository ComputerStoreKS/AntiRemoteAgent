## What is AntiRemoteAgent?

Anti-Remote Agent is a Windows security application built to stop one of the most damaging scams targeting everyday computer users: the **tech-support scam**, where a criminal on the phone or a fake "virus warning" convinces someone to hand over remote control of their PC.

Once a scammer has remote access, they can drain bank accounts, install malware, steal personal files, and lock the victim out of their own machine — all while the victim watches. Anti-Remote Agent is designed to shut that door before it opens, and to keep it shut.

It runs quietly in the background, protecting the computer around the clock without getting in the way.

---

## Who is this for?

This tool was built with **non-technical users in mind** — particularly the people scammers target most often: older adults, families helping protect their parents, and anyone who isn't confident about what's safe to click.

It's also a practical layer of defense for:

- Small businesses and home offices
- Schools and community centers with shared computers
- IT technicians setting up a machine for someone they want to keep safe
- Anyone who simply wants peace of mind

You don't need to understand how it works to be protected by it. Install it, and it does its job.

## What it protects against

Anti-Remote Agent defends against the full toolkit a scammer relies on:

### Remote-access takeovers
The app recognizes the remote-control programs scammers use to operate a victim's computer — both the well-known commercial ones and the lesser-known tools criminals favor specifically because they're obscure. If one of these tries to run, the app steps in.

### Scam and phishing websites
Many scams start with a fake webpage — a phony "Microsoft alert," a counterfeit login page, or a site pushing a malicious download. Anti-Remote Agent blocks a large and continuously updated list of known scam, phishing, and malware websites so they never load in the first place.

### "Your computer is infected" lockup pages
Some scam pages take over the entire screen with a fake warning and a phone number, hiding the taskbar and making the computer feel broken. Anti-Remote Agent recognizes these hijack pages and clears them automatically.

### Malicious downloads
If a scam tries to slip a dangerous file onto the computer, the app catches it as it arrives — before it can be opened or run.

### Unwanted and deceptive software
Beyond outright scams, the app also watches for **potentially unwanted programs** (PUPs): fake "PC cleaners," bogus driver updaters, browser hijackers, adware, and other junkware that degrades a computer and is often bundled alongside scams.

### Hidden and disguised threats
Scammers frequently rename their tools or disguise them as something harmless. Anti-Remote Agent is built to see through those disguises rather than being fooled by a filename.

## How to use it

1. **Install** — run the installer and follow the prompts. Administrator approval is required so the app can protect the system properly.
2. **That's it** — protection starts immediately and runs automatically every time the computer starts.
3. **Check in any time** — open the app from the system tray to run a manual scan, review settings, or see what it's protecting against.

When the app blocks or removes something, it will let you know with a clear notification. In most cases, there's nothing for you to do — it has already handled it.

---

## A note on remote-access software

Remote-access tools are not inherently bad — IT departments and support providers use them legitimately every day. The danger is **who is on the other end**.

AntiRemoteAgent treats these tools as a risk by default because that is overwhelmingly how they're used against the people this app protects. If you have a genuine, trusted reason to use one, the app lets you make that exception yourself — but it will never make that decision for you, and it's intentionally designed so a stranger on the phone can't talk you through disabling your own protection.

**If someone you didn't contact first is asking you to install remote-access software or turn off your security — that is the scam. Hang up.**
